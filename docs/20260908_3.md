## 修補 WebShell 風險

```mermaid
flowchart LR
    Start([附件上傳]) --> Choice{"是否因特殊需求<br/>必須存放於專案目錄？"}
    Choice -- 否 --> ValidateFileService[後端檢查檔案格式]
    ValidateFileService --> FileService[將附件上傳至 File Service]
    FileService --> Safe([完成])
    Choice -- 是 --> Validate[後端檢查檔案格式]
    Validate --> Directory[建立檔案上傳專用目錄]
    Directory --> WebConfig[在專用目錄放置 web.config]
    WebConfig --> Safe

    classDef decision fill:#fff7d6,stroke:#8a6418,color:#2b2415,stroke-width:2px;
    classDef preferred fill:#e8f3ec,stroke:#33704a,color:#173b27,stroke-width:2px;
    classDef required fill:#fde8e7,stroke:#b42318,color:#7a1812,stroke-width:2px;
    class Choice decision;
    class FileService,Safe preferred;
    class ValidateFileService,Validate,Directory,WebConfig required;
```

專用目錄下的 `web.config` 內容：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <system.webServer>
        <handlers accessPolicy="Read" />
    </system.webServer>
</configuration>
```
